Building and Running our Engine

To run our game engine, view this GitHub Repository . Copy the repository, navigate to Demo_Engine/engine, and run dub.

Note, make sure to have the dependencies outlined in dub.json installed.

Portmorteum

Overall, we really enjoyed this project! It was very fun to combine everything we learned in the class and create a small engine of our own. We’ve overall satisfied with the final game we created, the json reading, and architecture of the engine.

Our biggest challenge was managing our time well. If we were to do the project again, we would plan more early and start coding much earlier. We had many ideas that we wanted to implement, and had we had more time to finish the project, we would’ve added a more robust tile editor, more levels to our game, and just overall cleaned up our code. We wanted to add lights for the guards to change the lighting and make it feel more like night. We also wanted to add more animations to our game.

We added some sound, but adding other assets and media would’ve been a nice touch to our engine as well.

Some of the most difficult things to add were making sure the scenes work properly, especially the cut scenes, which is our special feature. We also spent a long time implementing our json reader functions.
